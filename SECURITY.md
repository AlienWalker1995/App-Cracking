# Security policy

## Supported versions

The `main` branch is the supported version. Releases, if any, are cut from `main`.

## Reporting a vulnerability

Please report security issues privately, not in public issues.

- Use the repository's **Report a vulnerability** button (GitHub Security Advisories) to open
  a confidential advisory.
- Do not open a public issue for a suspected vulnerability.
- Do not include a personal email address in the report; the advisory channel is enough.

We aim to acknowledge reports promptly and to coordinate a fix before any public disclosure.

## Scope

This project is reverse-engineering tooling. It is intended to be used only on applications
you have the legal right to analyze. See [DISCLAIMER.md](DISCLAIMER.md) for the full
responsible-use terms.

This repository is expected to contain no secrets, no per-target keys, and no third-party
target data. If you find any, please report it privately.
